# U-EventTrack System Description
U-EventTrack is an event attendance tracking and management system developed for Mindoro State University - Bongabong Campus that automates attendance verification, manages student participation in campus events, and tracks financial penalties for attendance violations through an integrated multi-platform architecture. The system is built on a three-tier architecture consisting of a Laravel 13 backend API with SQLite database and Sanctum authentication, a React 19 desktop web application providing administrative interfaces for officers and administrators, and a React Native mobile application with Expo enabling students to participate in events and track their attendance records. This architecture ensures seamless communication between platforms while maintaining role-based access controls and data security.
The event management feature allows officers to create and schedule events with automatic status transitions from upcoming to ongoing to completed based on real-time date and time validation. Events include GPS coordinates and radius parameters that enable location-based verification during student check-ins. The attendance tracking system supports three distinct verification methods to accommodate different scenarios including manual entry that serves as a universal fallback, barcode scanning using student ID cards that provides speed and accuracy, and facial recognition through face-api.js that offers contactless biometric verification. The system captures both check-in and check-out times with GPS location validation to ensure students are physically present at event venues.
The student fines and penalty management feature automatically calculates financial penalties for attendance violations where whole-day events are divided into four attendance periods consisting of morning time-in, morning time-out, afternoon time-in, and afternoon time-out. Each period violation incurs a twenty-five peso fine, meaning morning time-in costs ₱25, morning time-out costs ₱25, afternoon time-in costs ₱25, and afternoon time-out costs ₱25, resulting in a total of one hundred pesos for a complete day of non-compliance. The system automatically processes attendance records including check-in times, check-out times, and attendance status to determine applicable penalties. Students can view their fines with details about the event, violation reason, amount owed, and payment status through both desktop and mobile interfaces while officers and administrators have comprehensive management capabilities including monitoring all student fines, updating payment status, waiving penalties when appropriate, and generating financial reports for accountability and tracking.
Student management maintains comprehensive records including academic information such as course and year level, unique barcode identifiers for quick scanning, and facial biometric data captured through multi-pose enrollment that records front, right, and left profile views. Each captured pose generates a 128-dimensional descriptor vector that represents unique facial characteristics in mathematical space, enabling reliable matching during check-in regardless of lighting conditions or slight appearance changes. User management implements role-based access control with three distinct levels where students can check in to events, view their personal attendance history and fines, and update their profiles, officers can manage events, monitor live attendance, enroll student faces, and manage fine payments, and administrators possess full system access including user account management, announcement control, and audit log review. All user types can enable two-factor authentication using time-based one-time passwords for enhanced account security.
The announcements system automatically generates event-based notifications for the public landing page based on event proximity where events happening today receive Alert status displayed in red, events happening tomorrow receive Reminder status in yellow, and upcoming events within a week receive Event status in blue, while administrators can also create manual announcements for important communications. The reporting and analytics features provide comprehensive attendance logs, event statistics, student participation histories, fine tracking summaries, and financial reports with export functionality for further analysis.
The technology stack leverages modern frameworks including Laravel 13 with PHP 8.3 for the backend providing robust API services, React 19 with Vite and Tailwind CSS for responsive desktop interfaces, and React Native 0.81 with Expo 54 for cross-platform mobile development. Security is implemented through Bcrypt password hashing with 12 rounds, optional TOTP two-factor authentication, Laravel Sanctum token management, role-based middleware protection, and comprehensive audit logging that tracks user actions with IP addresses and timestamps. The database schema includes tables for users, students, events, attendances, fines, announcements, and audit logs, all related through foreign keys to maintain referential integrity.
Key automated processes include face enrollment where officers capture three facial poses that generate 128-dimensional descriptors stored as JSON arrays for matching during check-in, the check-in process that verifies identity through barcode, facial recognition, or manual entry while validating location and creating attendance records, fine calculation that automatically assesses twenty-five peso penalties per violation based on attendance records, event status updates that run every five minutes to transition events based on current date and time, announcement synchronization that runs daily at 6:00 AM to generate notifications for upcoming events, and location verification using the Haversine formula to calculate the distance between student coordinates and event venue coordinates.
Setting up the system requires installing dependencies through Composer for the backend and npm for the frontend and mobile applications where the backend requires running migrations to create database tables and optionally seeding sample data including default administrator and officer accounts. The backend server starts with the command to bind to all network interfaces, enabling mobile devices on the same network to connect, while the frontend development server runs through Vite providing hot module replacement, and the mobile app runs through Expo allowing developers to scan QR codes with the Expo Go app for instant testing on physical devices.
The system is currently deployed as version 2.0 featuring barcode scanning, facial recognition attendance, mobile application support, automated fines management, two-factor authentication, and comprehensive audit logging. Default development accounts include an administrator with email admin@example.com and an officer with email officer@example.com, both using the password "password" for initial access. The platform is licensed and maintained by Mindoro State University - Bongabong Campus as of 2026.
